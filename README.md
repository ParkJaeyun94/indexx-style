# UNIT Magazine V2

GitHub Pages에 바로 올릴 수 있는 정적 HTML/CSS/JS 버전입니다.

## 구성
- `index.html` — 페이지 구조 및 기존 푸터/정책 내용
- `style.css` — 화이트 에디토리얼 디자인 + PC/태블릿/모바일 반응형
- `script.js` — 모바일 메뉴, 스크롤 등장 효과, 리뷰 이동, 정책 팝업
- `assets/` — 이번 대화에서 제공한 이미지

## 적용
기존 저장소에서 아래 파일을 교체/추가하면 됩니다.

1. `index.html` 교체
2. `style.css` 교체
3. `script.js` 추가
4. 이 폴더의 `assets/*.jpg`를 기존 `assets/`에 추가

기존 `CNAME`, `robots.txt`, `sitemap.xml`, favicon은 그대로 유지하면 됩니다.

## 참고
현재 히어로 및 일부 섹션 이미지는 전달받은 인스타용 이미지에서 구성한 버전이라,
나중에 원본 인물/스타일링 사진을 개별 이미지로 교체하면 품질이 더 좋아집니다.

## V2.1 튜닝
- 인스타 포스터 이미지의 텍스트를 피해 사진 영역만 웹용으로 크롭

- 모바일 타이포, 카드 비율, 여백, 리뷰 가독성 개선
- 기존 푸터 회사정보/정책 내용 유지
